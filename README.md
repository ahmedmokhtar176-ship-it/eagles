# Eagles Security Website

موقع React + Vite من 4 صفحات:
- الرئيسية
- خدماتنا
- عن الشركة
- تواصل معنا

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح الرابط الذي يعرضه Vite.

## الإنتاج
```bash
npm run build
npm run preview
```

### ملاحظات
- الصور حاليًا من Unsplash بروابط مباشرة ويمكن استبدالها بصور الشركة النهائية.
- رقم الهاتف والبريد والعنوان نصوص تجريبية قابلة للتعديل من `src/main.jsx`.
- الـ animations تعتمد على GSAP ScrollTrigger و Lenis.
